# Definition of Done

Ein AppForge-Pro-Inkrement ist fertig, wenn:

- [ ] Nutzerwert und Akzeptanzkriterien im Issue stehen
- [ ] Architekturgrenzen eingehalten sind
- [ ] neue Logik automatisierte Tests besitzt
- [ ] SwiftFormat und SwiftLint grün sind
- [ ] SwiftPM-Tests grün sind
- [ ] Xcode-Build und -Tests grün sind
- [ ] Fehlerzustände und Accessibility berücksichtigt sind
- [ ] relevante Dokumentation aktualisiert ist
- [ ] keine Secrets oder Benutzerdateien enthalten sind
- [ ] signierter Commit und PR vorhanden sind
- [ ] Review und CI erfolgreich sind
- [ ] PR gemergt und Board aktualisiert ist

Eine generierte App hat zusätzlich bestanden:

- [ ] deterministische Ausgabe und Lockfile
- [ ] Framework-Formatierung und Analyzer
- [ ] Unit-, Architektur- und Golden Tests
- [ ] Rollen- und Mandantentests
- [ ] Offline-/Reconnect-Test
- [ ] Datenbank- und Release-Anleitung
